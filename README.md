# B612·拾文

> 替你省下繁琐排版的时间，把时间留给真正热爱的事。

B612·拾文是一款 Windows 桌面文档工具，用于整理 AI 生成的 Markdown 内容，并将文字、图片和公式复制或导出到 Microsoft Word、WPS Office。

## v1.5.10 更新

- 修复连续求和符号大小不一致、公式中的空占位符和多余对齐标记；
- Word 和 WPS 分别使用各自接受的复制格式，保留可继续编辑的公式；
- 修复无括号矩阵的列结构，以及公式文字包含 `&` 时的转换失败；
- 明确指定正文与公式中的中文字体，按原文保留粗体范围；
- 复制在本机内存中完成，不启动 Word/WPS，也不生成临时 Word 文件。

复制前，请在软件的“设置 → 复制目标”中选择实际使用的 Word 或 WPS，再复制预览内容并粘贴。

Word 中需要保持原文的字体与粗体范围时，粘贴请选择“保留源格式”。“合并格式”会继承目标文档和插入位置的格式。

## 主要功能

- 打开、编辑和保存 Markdown 文档；
- Markdown 编辑与实时排版预览；
- 大纲折叠、展开和标题跳转；
- 复制排版后的文字、图片和公式；
- 支持 Microsoft Word 与 WPS Office；
- 导出可继续编辑的 Word 文档；
- 临时图片在清空或退出后自动释放；
- 保存 Markdown 时，将附属图片保存在文档旁的 `.assets` 文件夹。

## 安装说明

1. 下载 `B612-Shiwen-Setup-v1.5.10.exe`；
2. 双击安装，并根据提示选择安装位置；
3. 安装完成后启动 B612·拾文。

支持 Windows 10/11 x64；内置运行环境和 Word 导出组件。当前安装包未购买商业代码签名证书，因此 Windows 可能显示未知发布者或 SmartScreen 提醒。请确认安装包来自本仓库，并核对 SHA-256 校验值。

## 兼容性说明

已在本机 Microsoft Word 16.0.20326.20132 和 WPS 12.1.0.28599 中验证公式粘贴、内部编辑和删除；其他历史版本仍可能存在差异。带框公式复制后保留内部内容，去掉外框；多行推导保留为可编辑公式，暂不保证逐个保留 LaTeX 的精确水平对齐点。WPS 含公式的混合复制支持普通表格、列表及 PNG/JPEG/GIF 图片；跨行合并表格或未取得数据的图片会明确报错。

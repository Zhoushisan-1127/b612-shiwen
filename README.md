# B612·拾文

> 替你省下繁琐排版的时间，把时间留给真正热爱的事。

B612·拾文是一款 Windows 桌面文档工具，用于整理 AI 生成的 Markdown 内容，并将文字、图片和公式复制或导出到 Microsoft Word、WPS Office。

## 下载

请前往 [Releases 下载最新安装包](https://github.com/Zhoushisan-1127/b612-shiwen/releases/latest)。

当前版本：**v1.5.5**

下载时请选择：

- `B612-Shiwen-Setup-v1.5.5.exe`
- `B612-Shiwen-Setup-v1.5.5.exe.sha256`

## 主要功能

- 打开、编辑和保存 Markdown 文档；
- Markdown 编辑与实时排版预览；
- 大纲折叠、展开和标题跳转；
- 复制排版后的文字、图片和公式；
- 支持 Microsoft Word 与 WPS Office；
- 导出可继续编辑的 Word 文档；
- 临时图片在清空或退出后自动释放；
- 保存 Markdown 时，将附属图片保存在文档旁的 `.assets` 文件夹。

## 安装说明

1. 下载 `.exe` 安装包；
2. 双击安装，并根据提示选择安装位置；
3. 安装完成后启动 B612·拾文。

当前安装包未购买商业代码签名证书，因此 Windows 可能显示未知发布者或 SmartScreen 提醒。请确认安装包来自本仓库，并核对 SHA-256 校验值。
